# AI Repo Directory v1.0.0

The first public release of AI Repo Directory is a curated catalog of 256 independently verified open-source AI repositories across 16 categories.

Highlights:

- Searchable, shareable discovery across agents, RAG, inference, local AI, MCP, evaluation, training, and more.
- Editorial summaries, maintenance signals, and transparent composite scores.
- Static GitHub Pages deployment with no runtime GitHub API dependency.
- Weekly metadata refreshes and a reviewable data pipeline.
- Public issue forms for suggestions, corrections, bugs, and improvements.

The directory is curated rather than exhaustive. It does not claim real-time GitHub data or star-growth trending until sufficient history exists.
